## B1. How "differs from the sum of filed components" is decided (no ground truth in the DB)
I did not use one reference sum, because the tags do not say whether a long-term-debt tag already contains the current portion or a short-term tag. A stored value is flagged only with one of these deterministic tests, applied to the company's own tags at the same instant:
- IDENTITY TESTS (strong; arithmetic among the filer's own tags): (i) double count: `LongTermDebt - LongTermDebtNoncurrent` equals (within 0.2%, and closer to it than to LongTermDebtCurrent) a short-term tag or DebtCurrent that the stored sum then adds again; (ii) bare tag: `LongTermDebt` is smaller than `LongTermDebtNoncurrent`, `LongTermDebtCurrent`, or half of `LongTermDebtAndCapitalLeaseObligations`, yet it is the stored value; (iii) omission: `LongTermDebt = N + C` (so it includes current) and `DebtCurrent - C` exceeds 2% and DebtCurrent is not just one short-term tag, yet the stored value lacks it; (iv) a short-term tag outside the resolver's list (ShortTermBankLoansAndNotesPayable, ShortTermNonBankLoansAndNotesPayable, OtherShortTermBorrowings, CommercialPaper when ShortTermBorrowings was taken first) whose value equals the gap between the stored value and the composed reference; (v) zero stored while a debt tag is nonzero; (vi) stored value below a single filed instrument tag by more than 2% (a total cannot be smaller than one of its parts).
- INDETERMINATE (stored differs from the composed reference by > 2% but no identity proves why): listed, not counted as wrong, needs a Verifier filing check.
- The composed reference interval is: the company's own `DebtLongtermAndShorttermCombinedAmount` if filed; else the long-term block (LongTermDebt if containment-valid, else Noncurrent + Current, else the lease-combined variants) plus the short-term block (DebtCurrent minus the current part already inside LongTermDebt, but DebtCurrent alone when it equals one short-term tag; else the distinct short-term tags with duplicates of the current portion removed). Where scope is unknowable the interval has two ends.

## B5. Proposed composition rule for total_debt (proposal; nothing applied)
Per company and balance-sheet instant; us-gaap, USD, undimensioned, authoritative; leases excluded unless the filer's own tag combines them (then labelled "includes finance leases").
- R0 (exists): the company's own `DebtLongtermAndShorttermCombinedAmount` wins.
- R1 long-term block, take exactly one, in this precedence: (a) `LongTermDebtNoncurrent` + `LongTermDebtCurrent` (carrying lines) when both are filed; (b) `LongTermDebt` only if containment-valid (L >= N, L >= C, L >= 0.5 x LongTermDebtAndCapitalLeaseObligations) and no (a); (c) `LongTermDebtAndCapitalLeaseObligations` + `...Current` or `...IncludingCurrentMaturities` (lease-labelled); (d) `DebtAndCapitalLeaseObligations`. A rejected bare `LongTermDebt` never becomes the value.
- R2 short-term block: add only debt classified current that is not inside the long-term block. If DebtCurrent is filed and equals one short-term tag, add that DebtCurrent once; if DebtCurrent exceeds the current part already inside L (L - N, or C) add DebtCurrent minus that part; else add the single distinct short-term tag (ShortTermBorrowings, CommercialPaper, ShortTermBankLoans..., ShortTermNonBankLoans..., OtherShortTermBorrowings) left after dropping any value equal to L - N or to C. If two or more distinct short-term tags remain (BAC), refuse (nested vs additive is not decidable from tags).
- R3 instrument fallback, only when R1 yields nothing: use the broadest tag per family (ConvertibleDebt over its Current + Noncurrent parts), summed across families (NET, CME, CDNS, DLR, DHI, ...).
- R4 withdraw any `company_tag_preference` for total_debt whose tag is a single component rather than a total.
- R5 guard: refuse to publish (blank with reason) a value smaller than a single filed instrument tag by more than 2%, or a zero while any role/instrument debt tag is nonzero; a zero-valued tag must never select a path (skip zero-valued role tags when another role tag is nonzero).
Expected hits on the top 1000, latest FY (all-period counts in brackets, resolved concept): R1(b) containment/bare 6 [171]; R1(a) prefer N + C over differing L: 100 companies differ at the latest comparable period [1,122 instants]; R2 double count removed 3 [51]; R2 DebtCurrent omission 1 [83]; R2 outside-list short-term tag 7 [463]; R3 fills 66 blanks (single/multi split not run at FY) [3,301 blank instants; of 3,073 with instrument tags and no role tag: single instrument tag 1,459 (non-financial 1,308, SIC 6000-6199 151), multiple instrument tags 1,614 (non-financial 1,238, financial 376)]; R4 5 [222]; R5 stored below instrument tag 18 [636] and wrong zeros 1 [76] (base 12 [420]).
