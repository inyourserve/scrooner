## Headline findings
1. **Most "values differ" counts are a PoC implementation bug, not perimeter (FILING-CHECKED cause, DATA-INFERRED count).** `structural_concepts_poc.py` takes the first matching row in `pre.txt` FILE order, which is not statement line order. Sorting by (report, line) and changing nothing else: D&A differ 61 -> 20, capex 29 -> 5, interest 7 -> 2. In 6 of the 8 sampled differ cases the R-file shows the name-path line ABOVE the line the rule picked (ADI R10 row 3 vs 4; Comtech R8 3 vs 5; Costco R8 13 vs 37; Pathward R9 31 vs 32; MACOM R8 21 vs 23; UTI R8 23 vs 50).
2. **"Agree" does not mean "correct".** After the fix, ADI, Comtech, Pathward and MACOM agree, but both paths return a component: ADI depreciation 406,801K only (D&A incl. intangibles = 406,801 + 1,592,044 = 1,998,845K, no total line); Comtech 11,798K is PP&E-only (plus 21,723K intangibles). Perimeter is real but hides inside the agree bucket, which doc 39 did not inspect.
3. **Real production-relevant defect: D&A tag precedence.** Our mapper (`mapper/expanded_concepts.py` ~line 300) ranks `DepreciationAndAmortization` priority 1 and `DepreciationDepletionAndAmortization` priority 2. At Kura and Starbucks the priority-1 tag is an income-statement SUB-line; the CF total is the priority-2 tag. Kura: 448K shown vs 14,046K true (31x low). FSDS 2025q4: where both tags are filed for the same filing and duration, they differ in 137 of 394 filing-periods (10-K 7 of 14; 10-Q 130 of 380; 115 of the 137 have DA < DDA). Production effect is DATA-INFERRED (DB not queried).
4. **FSDS `num.txt` holds face-statement facts only** (DLH: 77 distinct tags in num = 77 in pre; the note fact `InterestExpenseNonoperating` 13,360K in R55 and in companyconcept for this accession is absent from num.txt). So the PoC name path under-counts what companyfacts/our `core.fact` sees; "structure-only" counts are partly an FSDS-scope artifact.

## What this means for doc 39
- Its central claim ("values differ is high because filers compose these lines differently") is not supported: 78% is the PoC itself. Doc 39's own stop rule (fewer than half explained by perimeter) is already met on this evidence.
- Perimeter is still real, but it shows up (i) inside cases where both paths agree on a component and (ii) as tag-precedence errors in our own name path. The cheapest high-value fix is a statement-anchored precedence for D&A: prefer the tag on the cash-flow statement total over an income-statement line tag, verified against the filer's CF. This is a proposal for the Tag Mapper / Standardization Lead, not an approved rule.
- Revenue/interest structure-only cases (NJR, Nikola, Photronics, DLH) are all correct on the structure side; 3 of 4 are custom tags or a tag our mapper rejected for population-level conflicts, so they need a statement-anchored rule, not a vocabulary addition.
