# Rules (the Tag Expert's knowledge as data)

LEARNING-SYSTEM.md §1-2. One CSV per namespace (bs, is, cf, notes, per_share, bank, insurer, company, …). Columns: rule_id, version, namespace, data_point, scope, era, kind, when (JSON), then (JSON), precedence, evidence, author, date, note.

Rule kinds the engine (exam/tools/predict.py) evaluates: `tag` (stmt + tag → decision/concept), `override` (company scope, cik + tag), `combined_concept`, `label_demote` (label regex → combined), `prefer_tag`, `note_fact` (ordered note facts), `note_default`, `bank_tag`, `sector_detect`, `sector_out`, `unclassified_np`, `sum_allowed` (duration sums; total_debt), `stmt_restrict`, `parenthetical_allowed`, `data_point` (template vocabulary + home statement), `procedure` (parameters of a structural procedure: opex band tie, receivables single line, net income without a parent line, lone D&A, capex sum, plain-caption net interest, sole-debt interest, lone G&A, interest income inside a net line).

Migration 2026-11-13: generated by exam/tools/migrate_rules_from_v6.py from predict.py v6 and the library CSVs; parity check exam/tools/parity_v6_v7.py: 997 companies, 52,841 rows, 0 differences against v6 (excluding the version string and the new rule_ids column).
Change rules only through the backtest (LEARNING-SYSTEM.md §4); proposals go to rules/inbox/.
