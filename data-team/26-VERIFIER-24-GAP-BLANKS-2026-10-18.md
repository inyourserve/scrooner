- `cash_and_equivalents`: CashAndCashEquivalentsAtCarryingValue, CashCashEquivalentsRestrictedCashAndRestrictedCashEquivalents. It does not include the plain `us-gaap:Cash` tag.

## Headline finding: the triage's main proposed fix is wrong
The triage note "Operating Income ... derivable as Revenues - CostsAndExpenses" fails on the filings. For CVX, AJG and HTZ the `CostsAndExpenses` total **includes interest expense** (and for CVX, other deductions too), so Revenues - CostsAndExpenses equals **pretax income**, not operating income:
- CVX FY2025: 189,031 - 169,288 = 19,743 = `IncomeLossFromContinuingOperationsBeforeIncomeTaxes...` 19,743 ($M).
- AJG FY2025: 13,942 - 12,071 = 1,871 = pretax 1,871 ($M). Interest 639 sits inside "Total expenses".
- HTZ FY2025: 8,504 - 9,334 = -830 = pretax -830 ($M). "Interest expense, net" 1,077 sits inside "Total expenses".
- DHI files no `CostsAndExpenses` at all.
Shipping the CostsAndExpenses derivation would publish pretax income labelled as operating income for these issuers, which is a material wrong value. **Rejected.**

## Rule-level notes for the owners (proposals, not approvals)
1. Operating income when the statement has no subtotal (Standardization Lead). Revenue - CostsAndExpenses is pretax for CVX, AJG and HTZ. Options to decide: (a) leave it blank with the reason "operating income not presented"; or (b) define a derived EBIT-like figure (for example, pretax plus interest expense, or a component sum) with a visible "derived" label. yfinance's own figure is a component sum that drops non-operating lines; for CVX it also drops equity-affiliate income. These definitions give different numbers (AJG: Revenue - (CostsAndExpenses - Interest) = 2,510 vs yfinance 2,556). Whatever rule is chosen needs a full-population check against companies that DO tag OperatingIncomeLoss.
2. SG&A as opex (Tag Mapper / Standardization Lead). DHI and BBW present Revenue, CoR, SG&A, then non-operating lines. Letting SG&A feed `operating_expenses_resolved` when it is the only opex line reproduces yfinance exactly for both. It needs a coexistence check against companies that file both OperatingExpenses and SG&A.
3. Debt vocabulary (Tag Mapper). These need a full-population coexistence check against the existing components before adding: NotesPayable (sometimes a total, sometimes a component), NotesPayableCurrent + LongTermNotesPayable (a split pair, at risk of double counting with LongTermDebt*), LongTermLineOfCredit / LineOfCredit (CATO's LineOfCredit sits under a dimension member), SeniorNotes, SubordinatedDebt, AdvancesFromFederalHomeLoanBanks.
4. Zero borrowings (Standardization Lead / founder release policy). For CATO the filing explicitly states no borrowings and tags LineOfCredit = 0. ATEX has no debt line or note at all. Pack policy forbids turning missing into zero, so showing D/E = 0 needs an approved rule (for example: the filing states no borrowings, or the balance sheet has no debt line and no debt note). Until then, display "no borrowings reported". yfinance's nonzero figure is operating leases.
5. Net interest tags (Standardization Lead). VVX and UNIT present only "Interest expense, net" (InterestIncomeExpenseNonoperatingNet). For UNIT, R84 shows no interest-income netting, but the tag is the same one that other filers use for true net figures. This would need a company-scoped decision, not a global mapping. CDNL's InterestExpenseNonoperating is an expense-side tag, a cleaner candidate.
6. HTZ tags pretax income as `IncomeLossAttributableToParent`. Check whether `income_before_tax` is blank for HTZ too (not in this batch).
7. NUTR: Company Master shows `active`, but Form 25-NSE was filed 2026-10-07 and no 10-K exists. Route to Company Master status (not data-team mapping).
