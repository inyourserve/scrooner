# docmap.py changelog

Shared document-first read tool (`data-team/companies/reads/tools/docmap.py`), owned by the cloud reader session. Fixtures: `test_docmap.py` (offline; one synthetic 10-K, one assertion per fix). Run: `uv run --project pipeline python -m pytest -q data-team/companies/reads/tools/test_docmap.py`.

## 2026-11-12: fixes from NOTES-TAG-EXPERT-reads-101-110-2026-11-12.md (main e545bafb) + SG&A
Every fixture fails on the previous tool and passes on this one (7/7 each way).
1. **Co-registrant facts never count twice:** a tag repeated on one statement page (co-registrant block) counts once, parent/consolidated only (PLD debt 70,074 → 35,037). `dedupe_coreg`, test_1.
2. **NOTE values only from undimensioned consolidated facts:** a note hit needs a companyfacts (undimensioned) value for the same accession and period, and note pages titled VIE / subsidiary / merger / acquisition / segment / investee / equity method / joint venture / unconsolidated / discontinued / guarantor / parent-only are rejected (MCK, PSX, BWXT, SEIC). `NOTE_REJECT`, test_2.
3. **D&A includes `AdjustmentForAmortization`** when the face prints it (MCK, SYK). `DA_PARTS`, test_3.
4. **Interest face line variants:** `InterestAndDebtExpense`, labels "Interest and debt expense" / "Interest and other financing costs" (PSX). test_4.
5. **REIT capex:** with no PP&E-purchase line, a component sum of development, property/capital improvements and TI/leasing-commission lines; acquisitions excluded (PLD). `REIT_CAPEX`, test_5.
6. **Dividends on common AND preferred / units / NCI → combined;** preferred- or NCI-only lines stay excluded (PLD). test_6.
7. **SG&A is never G&A alone** when a selling or marketing line is printed: component sum of G&A + every selling/marketing line (LYFT 1,877,231,000 ties companyfacts). test_7.

Earlier 2026-11-12 rulings already in the tool: FY2015-to-latest eras (FY2015 10-K opened), whole-filing (MetaLinks) resolution of face misses with `check: machine-full-filing`, opex never includes cost of revenue, interest gross-only (net line combined), D&A with accretion combined, shares at the BS date (cover count never used), buyback withholding / NCI-preferred dividends / interest-notes-financing receivables excluded, bank and insurer OUT data points (SIC).

## 2026-11-12 (later): from cloud Ritwik's hand checks, ranks 131-150 (Dhairya 2026-11-12)
13. **Member rows of one tag are summed:** a line printed as several member rows on one tag (e.g. cost of revenue by product / service) is a component sum of ALL printed member rows, written `tag[member: <label>]`, value_source fsn_xbrl, and compared with the tag's undimensioned (consolidated) fact. A row equal to the sum of the others is the printed total and is used alone. The co-registrant de-duplication (fix 1) now drops a repeated tag only when its values are equal, so member rows survive. Cases: INTU 4,253, AMT 2,748.1, WMB 2,199, REGN 2,100.7, CDNS. test_10.
14. **Total debt never adds a printed total and its components:** when one printed debt line equals the sum of the others, it is used alone (PNC 95,743 vs 57,101). test_1 now also carries current + noncurrent components of the printed 1,500.
15. **REIT dividends = distributions paid, never declared:** "distributions paid / to stockholders" labels and PaymentsOfOrdinaryDividends / PaymentsOfCapitalDistribution join the family; "declared" lines and tags are excluded. test_11 (guards the label path; passes on the previous tool too because it already preferred the paid tag).
16. **Co-registrant blocks are never member rows:** a repeated tag with the same printed label is a co-registrant block (Ameren Corp / Union Electric / Ameren Illinois print one statement each), so only the first (parent) counts, even when the values differ. Member rows are told apart by their different labels (Product / Service). Fix 13 had summed AEE's three blocks (47 printed-vs-API mismatches across the range, now 0). test_12.

## 2026-11-13: from the blind-grade key errors on ranks 901-1000 (grade.py on main @58d9efd0, Dhairya 2026-11-13 adjudications)
17. **Dimension blocks are read by their header row:** rows under a `dei:LegalEntityAxis` header (or a multi-dimension header such as "Electric | Ameren Missouri") are a co-registrant / subsidiary block and are dropped whole. Rows under any other axis (product / service members) are kept whole, even when the label repeats (BLCO prints "Cost of goods sold" under each product member). Fix 16's same-label rule now applies only to the undimensioned face block. **Financial template groups:** for a group in `group_assignment_v2.csv` of bank, insurer, lender_nonbank, bdc, broker_dealer, asset_manager or reit_mortgage, a not-presented COGS / gross profit / R&D / inventory / current assets / current liabilities row is OUT (SYF CA/CL ruling; CACC). A presented line is never overruled by the group alone. The SIC rule for banks and insurers is unchanged. test_13, test_17.
18. **A total with cost of revenue printed only by member is never opex:** with no gross profit and no COGS line on the face block, but COGS rows in the member blocks, the face lines between revenue and the printed total are a component sum when they plus the member COGS tie to the total (BLCO 4,988 = 2,938 + 2,050; CZR 9,628 = 3,885 + 5,743). When they do not tie, the total is combined (WH: 444 + 565 vs 1,027). OperatingCostsAndExpenses joins the total-line tags. test_14.
19. **Net interest found anywhere is combined:** the net-interest rule (label `net` / `income` / `deductions`, or a net-interest tag) now runs after the whole-filing note resolution too (DOCS "Interest income" on InterestIncomeExpenseNonoperatingNet). ProceedsFromRepurchaseOfEquity is never buybacks (INGR, founder 2026-11-04 item 4). test_15.
20. **Affiliate summarized-financial pages are rejected notes:** NOTE_REJECT adds "affiliated compan" and "summarized financial" (GATX's RRPF affiliate interest and debt). test_16.
21. **Debt carried only on finance-lease tags is total debt:** when the BS face prints no standard debt line but prints finance-lease lines (LSTR "Current maturities of long-term debt" on FinanceLeaseLiabilityCurrent), total_debt is their component sum (founder 2026-11-04 item 5).
