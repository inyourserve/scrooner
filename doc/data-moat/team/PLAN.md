## Approach (changed after the Chief's challenge)
Work by **rule family**, chosen by **weighted reach to what users see**, verified by **sample**, checked by **code over the whole population**. Not company-by-company (only for the golden verification set and long-tail exceptions), not "map all tags" (12,013 unmapped; 3,534 used by five or fewer companies).

## What the Chief corrected in my first proposal (accepted)
1. **Correctness before coverage.** Known wrong-value classes go first: stored value differs from an authoritative copy (39 of 52,464 sampled rows), mislabeled period columns and full-year values under quarter labels, stale negative weighted-average share rows.
2. **"A cycle must move a number" was too crude.** New concepts grow the denominator. Use a fixed denominator for gains and a guard number that must not worsen; a held mapping that prevents a wrong value counts as a success.
3. **Denominator work must not look like a gain.** Report three states: value / proven-absent-from-face / unknown, with both denominators shown. `line_not_presented_in_filing` is evidence, not proof (14-34% of values we hold show no face line).
4. **Selection by rule family, weighted by company band** (top 100 / 1,000), not raw tag counts. A 12-case sample with 0 failures bounds the failure rate at only about 25%, so every family also gets a full-population code check.
5. **The apply step needs an approver.** See release tiers below.

## Launch target (founder direction 2026-10-18: "all cells filled, and numbers correct")
"100% of cells filled" is rewritten as **100% accounted for**: every matrix cell is either (a) a correct value traceable to a filing, or (b) an explicit, reasoned non-value (not reported by the company / not applicable / not yet derivable, with the reason shown to the user). Filling a cell the company does not report would require a guess and would break the second half of the goal (correct numbers), so it is not done. Measured baseline 2026-10-13: 578,789 of 848,578 matrix cells have a value (68.2%); reasons are recorded for 22.8% of cells.
Launch-critical order: (1) stop wrong values (refresh_stale_fills, pending dry-run after the recompute); (2) fill gaps in the 33 concepts that feed metrics (EBITDA inputs, buyback inputs, incomplete numerator/add/subtract/denominator); (3) fill derivable quarters; (4) give every remaining blank a displayed reason; (5) Verifier sample against filings before launch. Founder direction 2026-10-18: launch date is ASAP, when ready; there is no acceptable wrong-value ceiling. Every displayed value is correct or visibly marked unavailable, and any wrong value the Verifier finds is fixed before launch (a sample size only measures what we have not found yet).

## Stale-fill fix: DO NOT APPLY AS WRITTEN (Verifier, filing-checked, 2026-10-18) - `data-team/28-VERIFIER-STALE-FILL-PROPOSALS-2026-10-18.md`
Full-population dry-run proposed 4,755 replacements. Verifier opened original filings for 82 of an 87-row risk-stratified sample: proposed value wrong in 31 (and in 21 of 37 sign flips), stored value correct in 28, proposed correct in 34. Cause: the code matches stored and primary rows by company+period only, never the source tag; 64% of proposals substitute a different tag (a subset, a continuing-ops subtotal, a segment figure, an oppositely signed or zero tag), 282 are derived values mixing filing vintages, 255 come from 8-K / DEF 14A. The `authoritative_older_than_stored` filing-date guard cannot see any of these. Required before any write: (1) same source tag on both sides, (2) primary not derived, (3) primary from 10-K/10-Q/10-K/A/10-Q/A/10-KT only, (4) sign flips and zeros to review, (5) the refresh removed from the nightly (`resolve_all_conflict_fills`) until a reviewed dry-run of the guarded version. Guarded subset is about 1,015 rows; a clean sample of 25 there is not proof for the class. Own reviewed paths: 146 arithmetic operating-income rows (stored value omits cost of revenue); 1,189 ProfitLoss -> NetIncomeLoss rows (needs the Standardization Lead's call that net income means attributable to parent). Also routed: derived Q4 EPS/dividends-per-share and impossible-sign derived values (Period Engineer); ANDE ASC 606-only revenue, GE quarterly revenue = GE Capital only, zero/inverted tags at SHFH/MOJO/QWTR/BEEM/ARKO, CSUI total assets (Tag Mapper/Standardization); no detector for filer period-label and context errors (Data Engineer).

## Guarded stale-fill: still NOT safe as a class (Verifier, 146 of 570 proposals filing-checked) - `data-team/29-VERIFIER-GUARDED-STALE-FILL-2026-10-18.md`
19 of 146 would write a wrong value (1 of 20 random). The new guards worked (no different-tag swaps, derived values, proxy/8-K figures, sign flips). Five remaining patterns need guards: (1) later filing has a period-label error (SWK, CB, Ford, RDI, MHH, WYY): review when the proposed value equals the same company/tag/unit value at another period or the period is outside the filing's comparative window; (2) total cash-flow tag used for a continuing-ops subtotal (MGNC, LRDC): review when the primary filing also reports discontinued-ops cash flows; (3) cash vs cash-plus-restricted-cash under one tag (FDCT): review when restricted cash appears at the same date; (4) non-USD unit (IVDA, TWD): unit must be USD and equal the stored unit; (5) not a real period (EONR one-day interest): reject durations under 80 days and roughly annual durations sourced from a 10-Q. Plus: reverse-split EPS (22 of 31 EPS proposals; GURE, NCRA, SVMB, BURU) are never refreshed per cell, since our split table lacks those splits and a cell-by-cell change would mix post- and pre-split values in one company's history (guard: share count changes 1.5x or more between filings; route to split handling).
DECISION (Dhairya, under founder delegation 2026-10-18, reversible): this refresh path applies restatements and corrections only. Re-presentations (discontinued operations, spin-offs, perimeter changes; 13 of 20 random proposals) and reverse-split re-basing are whole-series changes with their own owners and are never refreshed cell by cell, because one re-presented year inside an original-basis series breaks growth, TTM and ratios. Narrowest supportable first subset: no detector flag and primary form 10-K/A or 10-Q/A (about 106 proposals; 38 sampled had no wrong row), still needing its own reviewed dry-run before any write.
Wrong values displayed today, routed: IVDA cash is the TWD component (Tag Mapper); segment-note operating income mapped as consolidated (AAME, DuPont, Kilroy); LGND's shifted 10-K/A (Period Engineer); missing splits for GURE, NCRA, SVMB, BURU (split owner).
