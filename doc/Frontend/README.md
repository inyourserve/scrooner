# Scrooner `doc/Frontend/` — Purpose

Added 2026-09-06 (this folder existed and grew organically before then, but had no stated purpose or index entry — see the 2026-09-06 doc-consolidation audit that surfaced this).

**This is raw, unauthored reference material and working specs — not Scrooner's own design decisions or evidence.** Distinct from [`../design/`](../design/), which holds Scrooner's own numbered product-design framework, UX architecture, and implementation-evidence docs.

Contents:

- `holding/` — raw HTML captures of real competitor pages showing how they present ownership/shareholding data (Nasdaq, Yahoo Finance, Value Research, Trendlyne).
- `hero-header/` — a competitor company-page hero-header capture (`aapl-header-redesign.html`) used as visual reference.
- `reliance.html` — a competitor company-page capture.
- `financials/scrooner-financials-display-spec-final.md` — the working spec for the Financials section of the company page (Quarterly Results / Income Statement / Balance Sheet / Cash Flow Statement), used as the basis for the 2026-09-05 financials data-point gap analysis (`doc/learnings/2026-09-05-financials-spec-gap-plan.md`).
- `Inspector/v1.md` — a design/credibility audit of the Apple (AAPL) company research page.
- `Stock Detail Page — Frontend Implementation Brief.md` — an implementation brief for the stock detail page.

When a file here becomes the grounding for an actual scoping/build doc (the way the financials spec did), link to it from that doc rather than duplicating its content — this folder stays reference material, not a second copy of decisions.
